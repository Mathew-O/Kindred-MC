# AI-player conversation style
E-18/19/20 refine [the player product](../minecraft_player_spec.md). They do not alter the nine behavioral traits, skill eligibility or authority.

Clean defaults. Requested maturity/profanity/flirtiness/teasing/sarcasm/light dark humor are bounded by server caps and each actual recipient's preferences. Presets never opt other players in. Mixed audiences use the strictest applicable settings; public speech remains opt-in.

Lower settings/privacy changes invalidate queued speech. Finite and model dialogue share the same final delivery checks. No raw streamed tokens bypass policy. Qualify commands, persistence/migration, recipient changes, multiplayer delivery and absence of body/control side effects.
