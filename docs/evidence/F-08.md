## Scope and implementation
Replaces legacy mob-breaking fixtures with authentic native server-player log gathering ([NativePlayerBody](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/NativePlayerBody.java)) meeting survival requirements:

1. **Native Survival Mining Rules and Tool Wear**:
   - Mining is executed via [NativeGatherAction](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/NativeGatherAction.java) driving vanilla player delta breaking through `NativePlayerBody.mine(lease, target)` with hotbar selection.
   - Requires owned hotbar tool slot (0..8); tools take authentic item damage (e.g. iron axe wears 1 damage per break) directly on the player entity inventory stack without item cloning or manufactured replacements.
   - Preconditions require an active [PaidActivitySession](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-scheduler/src/main/java/dev/kindred/scheduler/PaidActivitySession.java) permit and valid `ActionArbiter` lease.

2. **Durable Ledger Admission and Patch Containment**:
   - Each target block break prepares and transitions a durable [ActionAdmission](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-core/src/main/java/dev/kindred/core/ActionAdmission.java) (`native_gather`) tracking pre/post evidence.
   - Targets are selected strictly within the acknowledged [WorkSetup.ResourcePatch](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-core/src/main/java/dev/kindred/core/WorkSetup.java). Blocks outside the designated patch bounds are never mined. If all matching blocks in the patch are exhausted, the action halts with an honest blocker (`"Blocked: no <block> left in the patch"`).
   - Concurrent tasks are fenced via [ClaimRegistry](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-core/src/main/java/dev/kindred/core/ClaimRegistry.java) resource claims (`block:<worldId>:<dimension>:<pos>`).

3. **Attributable Drop Collection**:
   - [ItemMoves.attributedPickup](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/ItemMoves.java) physically collects dropped item entities near the player into native player inventory slots.
   - Progress and admission verification require both the native break receipt and physical receipt of drops into inventory (`collected=N`).
   - If blocks break but drops cannot be collected (e.g. inventory full or drops pushed away), the gather action times out after 20 drop ticks without falsely claiming success (`"Breaking without pickup cannot complete gather"`).

4. **Checkpointed Resumption without Duplicate Harvesting**:
   - Inter-target transitions are safe checkpoint boundaries serialized to SQLite via [Checkpoint](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-core/src/main/java/dev/kindred/core/Checkpoint.java) (`initial`, `target`, `collected`, `remaining`, `need`).
   - Pause via `/player native lifecycle pause` smoothly ends active input, settles the activity permit, and saves progress.
   - Continuation via `/player native lifecycle continue` requests a paid activity permit, resumes the [SkillRunner](file:///c:/Users/matmu/Downloads/Kindred%20MC/companion-core/src/main/java/dev/kindred/core/SkillRunner.java) from the checkpoint, and gathers only the remaining need, never re-harvesting the initial count.
   - Autonomy loop prevents proposing conflicting tasks while a skill is paused.
