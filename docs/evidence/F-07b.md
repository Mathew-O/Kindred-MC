## Scope and implementation

User-visible behavior: none changed. This slice qualifies F-07's "death" criterion for the native body: real owned stacks, with their components, conserved through death and vanilla respawn.
- F-25b4 showed that two plain stacks (cobblestone and a pickaxe) drop and nothing is restored.
- These fixtures cover the cases it left open:
  - components (damage, a custom name, an enchantment);
  - worn armour and an offhand item;
  - several slots;
  - `keepInventory`, which F-25b4 lists as untested.
- No runtime fault was found, so `NativePlayerBody.respawn` is unchanged.

Changed modules/files:
- `NativeDeathConservationGameTests` (new; registered after `NativeAccountingGameTests`).
- The `keepInventory` fixture runs in its own batch. `@BeforeBatch` turns the gamerule on and `@AfterBatch` restores it, however the batch ends, since the rule applies to the whole world.
- The other fixture asserts the rule is off, so a restore that failed would show there.

Dependencies satisfied: F-25b4 (native death settlement and vanilla respawn), F-07a.
Schema/configuration changes: none.
