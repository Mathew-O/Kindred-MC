# F-08b — Recorded scoped native log mining
Date: 2026-10-15 EDT; native report 2026-10-16T01:18:14Z.
Antigravity / working tree. Complete for this child; F-08 remains open.

`/aiplayer native mine <x y z> <0..8 hotbar slot> <UUID>` executes a single scoped log break for an established native player body using native survival timing and tool wear. It requires explicit server edit policy opt-in (default denies; fixture/config bootstrap enables), active paid activity session (`PaidActivitySession`), an unexpired exclusive resource claim (`ClaimRegistry`), and durable `ActionAdmission` (`PREPARED` -> `DISPATCHED` -> single physical take). Target must be an intact log block without a block entity inside the player's acknowledged `WorkSetup` resource patch.

Only a matching `NativePlayerBody.MiningReceipt` from the Fabric AFTER event + durable `VERIFIED` record completes the action. Drops are explicitly recorded as `drops=unverified` (collection is not claimed). Cancellation/stop synchronously clears digging inputs, preserves intact log and tool, and closes with evidenced `FAILED` (no delayed break). Conflicting target changes or verification failures block the native body into `UNCERTAIN` without speculative retry or replay.
