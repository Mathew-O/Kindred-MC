# M-06d1 — Mobs' own griefing refused on claimed land

Date: 2026-11-11
Agent / branch: Claude, REFACTOR (`claude/refactor-tags-1109-10`, off main)
Build: see the PR's final commit
Status: in progress (CI on the PR)

## Scope and implementation

User-visible behavior: in a faction world, no mob changes a block on claimed land or in a safe zone of its own accord.
- An enderman takes nothing from there and sets nothing down there.
- A ravager tramples no leaves, a silverfish hides in no stone, and a wither tears through nothing.
- A zombie (or a vindicator, which uses the same goal) does not set about breaking a door there.

This is the same rule as for explosions. In the wilderness each does as in vanilla, and other modes are untouched (no
faction world, no check).

Changed modules/files:
- `TerritoryGuard.mayMobChange(world, pos)`: the explosion rule (`mayExplode`: refused on claimed land and in safe
  zones), on the server thread only, and passing when no faction world runs.
- Mixins (new), beside the nine there are. Each refuses before the change, so the mob never keeps what it was refused:
  - `EndermanPickUpTerritoryMixin`: the block an enderman looked at is not holdable there (`PickUpBlockGoal.tick`'s
    `isIn(ENDERMAN_HOLDABLE)`), so it neither removes it nor carries one.
  - `EndermanPlaceTerritoryMixin`: `PlaceBlockGoal.canPlaceOn` is false there; it keeps carrying its block.
  - `RavagerTerritoryMixin`: its leaf-breaking `breakBlock` in `tickMovement` is skipped there; nothing drops.
  - `SilverfishTerritoryMixin`: the stone there is not infestable to `WanderAndInfestGoal.start`; the silverfish stays out.
  - `WitherTerritoryMixin`: its block-breaking `breakBlock` in `mobTick` is skipped there. Its skulls' blasts were
    already spared by `ExplosionTerritoryMixin`.
  - `BreakDoorTerritoryMixin` with `DoorInteractGoalAccessor`: `BreakDoorGoal.canStart` is false for a door there, so
    the door is never cracked nor broken.
- Operator guide: the claimed-land protection line.

Cost: each check is `mayExplode`'s own lookup, the one explosions make per block. It runs only when a mob attempts a
change, never per tick:
- an enderman: after the block it looked at passes the holdable test, at most once a goal tick in twenty;
- a ravager: per leaf block, only while it collides;
- a wither: per block, once each time its cooldown runs out;
- a silverfish: in its goal's start;
- a zombie: when vanilla's own `canStart` says yes.

Dependencies satisfied: M-06d's claims and `TerritoryGuard`.
Schema/configuration changes and migration coverage: none. No saved key or event kind changed; the existing nine
mixins are unchanged.

## Acceptance evidence

`NativeMobGriefGameTests` (new). Each test has a pen in the wilderness, west of a chunk border, and one on the claim
east of it, the same mob in each.
- Endermen and silverfish act at random, so their own vanilla goals are found in their goal selector and ticked many
  times: the same code their AI runs, made certain.
- The ravager is pushed into a wall of leaves.
- The wither is hurt, which starts its block-breaking cooldown.
- The zombie, set to break doors on Hard, has an invulnerable villager behind the door.

In every test the wilderness control does what vanilla does: the enderman takes and sets down a block, the ravager
breaks leaves, the silverfish hides, the wither tears planks out and the zombie breaks the door down. So each claimed
pen's unchanged blocks are the claim's doing, not a mob that did nothing.

The fixtures' first run caught one mistake of their own: the chunk border was looked for among fifteen columns,
which can miss one. It is now looked for among sixteen.

No corpus gate: the diff stays on Factions paths (the guard's mob checks pass whenever no faction world runs).

Environment: Linux, JDK 21.0.12, the manifest's Minecraft 1.21.1 and Fabric.

## Remaining limitations and handoff

Not covered: a silverfish breaking out of infested stone already on a claim (it wakes its neighbours by breaking the
blocks it hides in, which an infestation placed there before the claim could still do), snow golems' trails, a
villager farming crops, a fox or a sheep eating grass, and an ender dragon's flight, which is not reachable from a
faction world's Overworld claims.
