# E-36 — An AI player names its pet (2026-10-29)

Agent / branch: Claude / claude/modest-faraday-r3spro
Build: 56c022f
Status: in progress. A pet is named with a real name tag, lettered at an anvil with a name of the player's own, and the name's origin remembered. Remaining: a name registry beyond memory notes, correction of a name, names for places and builds in play, and the strategist's names for pets.

## Scope and implementation

- **The name** (`NameForge.propose`, subject `PET`). A name of its own, in keeping with its temper, and not one its other pets have.
- **The tag** (`native_rename`, E-16d's anvil rename). With an unnamed pet, a blank name tag and a level to spare:
  - at an anvil it knows, it letters the tag with the name;
  - with none, it puts down an anvil of its own if it has one, as for naming its kit.
- **The naming** (`NativePetAction`, mode `name`). It uses the lettered tag on its own pet, as a player's use click does. Vanilla takes the tag and names the pet. Exactly the tag is spent, and the pet must bear the name after. Only a pet of its own is named.
- **Said and remembered.** "My wolf is called Molly now." A memory note keeps where the name came from: a tag it lettered at its anvil, a name of its own.
