# F-05a — Acknowledged single-use durable action admission
Date: 2026-10-15 EDT. Codex / uncommitted main, no commits. Complete for this foundation.

ActionAdmission wraps existing ActionRecord prepare/transition writes on an injected existing writer. Matching durable PREPARED and DISPATCHED acknowledgements, delivered to the owner, precede one explicit `take`. Callbacks never perform world actions. Taken admission still needs current arbiter, payment, claims and native policy checks. Verified/no-effect outcomes need adapter evidence and durable acknowledgement. Close revokes immediately and flushes immutable records without owner ticks: unissued work cancels/fails with absence evidence; issued work without an outcome becomes UNCERTAIN. Unknown/mismatched writes block without retry.

The existing SQLite writer now rejects altered intent/task revisions, preconditions and recorded pre-effect evidence. Invalid state-transition rejection order is preserved. No writer, schema, dependency or physical inventory store was added.
