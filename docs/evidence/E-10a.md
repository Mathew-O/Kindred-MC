## Scope and implementation

User-visible behavior: with the Kindred client mod installed, **K** (rebindable under Controls → Key Binds → Kindred AI Players) opens a panel. It lists the roster (Kindred, Sol, Vesp) with skin heads and spawn buttons, and for a selected AI player shows health, food, position, daily activity cap, goal and goal progress, with Start Nether run, Stop, Resume, mode, team, cap −/+, Connect/Disconnect, World edits and Close. Roster players wear their own bundled skins.

Changed modules/files: `KindredClient` (key binding, `GLFW_KEY_K`), `KindredPanelScreen` (client screen, refreshes every 20 ticks), `KindredPanelPayloads` (`kindred:panel_request`, `panel_action`, `panel_state`), `KindredPanelService` (server side: every button runs the same runtime command path as `/aiplayer`, under the requesting player's own command source and permissions, with operator-only actions gated at level 2), `CanonicalRosterSkins` (core), `RosterGameProfiles` (adds the `kindred_skin` profile property, plus signed textures from `config/kindred_skins.properties` when an operator supplies them), `mixin/client/PlayerListEntrySkinMixin`, bundled skin textures and `en_us.json`.
Schema/configuration changes: optional `config/kindred_skins.properties`. No save changes.
