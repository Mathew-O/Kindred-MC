# F-27a3a — The leftover count skips the periodic cost line

Date: 2026-11-22
Agent / branch: Claude, LOOPS / `claude/leftover-cost-line-1122`, from main `ce74e567`, at the lead's word
Design parent: F-27a3 (the leftover count skips a stop's own lines)
Status: complete (2026-11-22). Harness only: it changes a report, not behaviour, so no corpus gate.

## Scope and implementation

**Found:** REFACTOR found that every one of a run's 34 "replay players still acting after their own batch" was the
periodic "Kindred cost: day N" line. Since F-32d (`ef7f56a6`), that line's "webs by player, held/kept for good" lists
every player the Record holds a web for, including replay players whose batches ended long before. So `leftover()` read
the line as those players acting.

**Changed files:**
- `tools/corpus/report.py` `leftover`: a line holding "Kindred cost: day " is skipped, as F-27a3's stop lines are.
- `tools/corpus/test_leftover.py`: two new tests:
  - a cost line naming players after their batches must not count;
  - a real action after its batch, beside the cost line, still must.

**Schema/configuration changes:** none.

## Remaining limitations and handoff

- The skip is on the line's fixed opening. A cost line reworded without "Kindred cost: day " would be counted again; the
  test names the line it guards.
- Earlier gates' reported leftover counts since `ef7f56a6` include this over-count. They are not re-scored here.
