## Scope and implementation

- **Watched once seen** (`PlayerRuntime.checkPets`). Each second the runtime looks to each pet a player has seen of its own.
  - A pet since killed is told as the game tells it: "Molly is dead." Or with a cause: "Molly is dead: slain by Zombie."
  - It is then forgotten: its name and the record that it is known.
  - A pet only unloaded with its chunk is not taken for dead.
- **Not the mod's death hook.** Fixtures run their own runtime, which the mod's global hook does not reach (run p3 found this). The check is made by the runtime itself, so it holds the same in fixtures and on a server.
- **A death mid-naming.** The naming click is verified against the pet even if it has just died: the tag spent, the pet bearing the name. Run p3 found the player blocked for reconciliation when the fixture killed the wolf the tick it was named.
