## Scope and implementation

User-visible behavior: the operator gives one provider's API key and the strategist uses that provider's small, fast model.

| Key | Default model | Transport |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | `claude-haiku-5-5` | official Anthropic SDK (unchanged) |
| `OPENAI_API_KEY` | `gpt-4o-mini` | chat completions, strict JSON schema |
| `GEMINI_API_KEY` / `GOOGLE_API_KEY` | `gemini-3.5-flash-lite` | Gemini's OpenAI-compatible endpoint, JSON schema |
| `GROQ_API_KEY` | `openai/gpt-oss-20b` | chat completions, JSON schema |
| `MISTRAL_API_KEY` | `mistral-small-latest` | chat completions, JSON schema |
| `DEEPSEEK_API_KEY` | `deepseek-chat` | chat completions, JSON mode |
| `XAI_API_KEY` | none: `KINDRED_STRATEGIST_MODEL` required | chat completions, JSON schema |
| `OPENROUTER_API_KEY` | `openai/gpt-4o-mini` | chat completions, JSON schema |
| none, with `KINDRED_STRATEGIST_BASE_URL` | `KINDRED_STRATEGIST_MODEL` required | any OpenAI-compatible server (Ollama, LM Studio, a proxy) |

- The defaults were checked against the providers' announcements on 2026-10-21. Groq retired `llama-3.1-8b-instant` on 2026-08-16 and points to `openai/gpt-oss-20b`. Gemini's current Flash-Lite is 3.5, generally available since 2026-07-21. xAI's cheap line-up was contradictory across sources, so no default is guessed.
- Choice: an explicit `KINDRED_STRATEGIST_PROVIDER` wins; else a generic `KINDRED_STRATEGIST_API_KEY` is recognised by its prefix (`sk-ant-`, `sk-or-`, `gsk_`, `xai-`, `AIza`, then `sk-` for OpenAI); else the first provider-specific key in the table's order. `KINDRED_STRATEGIST_MODEL` and `KINDRED_STRATEGIST_BASE_URL` override.

Changed modules/files:
- `companion-model`:
  - `Strategist` (new): the interface every provider implements, with the shared `Outcome`, deadline, output cap and token reservation.
  - `StrategistPrompt` (new): the instructions and the meaning of each reply field, moved out of `ClaudeStrategist` so all providers get the same text.
  - `StrategistProvider` (new, pure): the choice above.
  - `OpenAiCompatibleStrategist` (new): the JDK's `HttpClient` and Gson.
    - A strict JSON schema generated from the same enums core validates; JSON mode with the fields described where a provider has no schema enforcement.
    - One repair in JSON mode when a provider refuses the schema (AI-05).
    - Usage and cached-token counts read from the reply.
    - A fenced JSON reply is accepted.
  - `Strategists` (new): builds the chosen strategist. The Anthropic path sits in its own nested class, so only it loads the Anthropic SDK.
  - `ClaudeStrategist`: implements `Strategist`; `withKey` for a key from any setting; otherwise unchanged.
  - `build.gradle`: `compileOnly`/`testImplementation` Gson 2.10.1, the version Minecraft 1.21.1 ships and supplies at runtime. Nothing new is bundled.
- `companion-server-adapter/StrategistBridge`: builds through `Strategists.fromEnvironment(System.getenv())`, logs the provider, and reports an incomplete setting by name.

Dependencies satisfied: F-19b.
Schema/configuration changes and migration coverage: new optional environment variables only; the old Anthropic settings work as before.
Requirements covered: AI-01, since providers are optional, use operator keys, and a local open-source server can serve it. AI-02 and AI-03, since every provider's reply goes through the same core validation. AI-05, since the bounds are unchanged and there is at most one repair.
