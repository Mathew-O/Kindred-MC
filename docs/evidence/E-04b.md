## Scope and implementation
Implements authentic native block placement ([NativePlaceAction](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/NativePlaceAction.java), [NativePlayerBody.placeBlock](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/NativePlayerBody.java)) and 3x3 workstation tool crafting ([NativeCraftAction](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/NativeCraftAction.java), [NativePlayerBody.craft3x3Internal](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/NativePlayerBody.java)) to advance earned survival tool progression without cheats or free items:

1. **Native Block Placement Under EditPolicy**:
   - Executes block placement via `NativePlaceAction` using vanilla `BlockItem.place(ItemPlacementContext)` semantics on the server thread.
   - Enforces reach validation (<= 4.5 blocks), support block presence, loaded chunk bounds, and server `EditPolicy` within assigned work scopes.
   - Durably fenced by `ActionAdmission` (`native_place`) with exact single-use transitions: PREPARED -> DISPATCHED -> VERIFIED.
   - Consumes exactly 1 item from the specified inventory slot; verified by inventory snapshots before and after mutation.

2. **Workstation Proximity Search and 3x3 ScreenHandler Crafting**:
   - `NativePlayerBody.findNearbyBlock` scans loaded blocks within reachable radius (<= 4.5 blocks) for an authentic `Blocks.CRAFTING_TABLE`.
   - Rejects 3x3 crafts if no crafting table is within reach, leaving inventory intact.
   - Opens an authentic `CraftingScreenHandler` via `ScreenHandlerContext.create(world, pos)`.
   - Distributes recipe ingredients into 3x3 matrix slots 1..9, captures vanilla crafting result in slot 0, and triggers `CraftingResultSlot.onTakeItem`.
   - Remaining/unused ingredients in the 3x3 grid are returned to native player inventory, ensuring strict item conservation with zero dupe or item loss.

3. **Durable Ledger Admission and Fencing**:
   - Fenced by [ActionAdmission](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-core/src/main/java/dev/kindred/core/ActionAdmission.java) (`native_place` and `native_craft`).
   - Single-use PREPARED -> DISPATCHED -> VERIFIED state pipeline with monotonic sequencing.
   - Preconditions require paid activity authority ([PaidActivitySession](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-scheduler/src/main/java/dev/kindred/scheduler/PaidActivitySession.java)), active `ActionArbiter` lease, and `EditPolicy` / `nativeMutationAllowed` permission.

4. **Strict Item Conservation Verification**:
   - `NativeCraftAction.verifyConservation` verifies consumed ingredients decrease by exact counts (3 planks and 2 sticks) and crafted product increases by exactly the recipe yield (1 wooden pickaxe).
   - `NativePlaceAction.verifyConservation` verifies exactly 1 placed block item decreases from inventory.
   - Ambiguous writes or physical state mismatches block for reconciliation (`UNCERTAIN`) without speculative replay.

5. **Autonomous Survival Tool Progression Ordering**:
   - [PlayerRuntime.evaluateNativeCandidates](file:///C:/Users/matmu/Downloads/Kindred%20MC/companion-server-adapter/src/main/java/dev/kindred/fabric/PlayerRuntime.java) priority ordering guarantees non-starving tool progression:
     1. Planks -> Crafting Table (score 57.5)
     2. Place Crafting Table in world (score 57.0)
     3. Wooden Pickaxe craft when reachable table exists + planks >= 3 + sticks >= 2 (score 56.5)
     4. Stick craft only when sticks < 2 and planks >= 2 (score 56.0)
