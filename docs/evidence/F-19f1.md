## 1. "cache read n/a" where the route never reports one

**Before.** On Anthropic's OpenAI-compatible layer, `usage.prompt_tokens_details` is always empty (Anthropic's page on
the layer). `OpenAiCompatibleStrategist` read the missing `cached_tokens` as 0, so the call line said `cache read 0`.
That reads as a measured zero, as in all 15 lines of RUNNER 2's run on main `399aeb7d`.

**Now.**
- `Strategist.reportsCacheReads()` is new. It defaults to true, as the native route always reports reads.
- `OpenAiCompatibleStrategist` answers false until a reply's usage carries `prompt_tokens_details.cached_tokens`, then
  true. It notes this where each reply is read (`noted`), for stances, questions, rescues, pages and talk alike.
- `ModelUsage.line(…, readReported, …)` and `ModelUsage.of(record, strategist)` print `cache read n/a` when the read
  is not reported. `StrategistBridge`'s three call lines (stance, voice, chronicle) use them.

The budgets are unchanged: they still count the cached figure as reported, 0 where none is.

So on Anthropic's compatible layer the line now reads, for example,
`in 7051, cache read n/a, cache write n/a, out 154 tokens, 1066 ms`.

## 2. The Anthropic provider when the SDK is absent

**Already fails closed; no code needed.**
- **The jar:** the release jar (`remapJar`) bundles `companion-model` but not its transitive Anthropic SDK
  (`include project(':companion-model')` only; the manifest's "not bundled in the release jar"). Checked on this
  branch's jar, below.
- **The one path to it:** only `Strategists.Anthropic.build` reaches the SDK, through `ClaudeStrategist.withKey`.
  `StrategistProvider`'s use of `ClaudeStrategist.DEFAULT_MODEL` is a compile-time constant, inlined, so it loads no
  class.
- **The failure:** without the SDK, building the Anthropic provider throws a `LinkageError` naming `com/anthropic`.
  `StrategistBridge.fromEnvironment` catches exactly that at start, in `PlayerRuntime`'s constructor, not on a tick.
  It then logs one line, `KINDRED_STRATEGIST is on with Anthropic but its SDK is not installed; playing without a
  strategist (the other providers need nothing more)`, and the runtime plays with memory only
  (`StrategistBridge.memoryOnly`): no strategist, no model call, no crash.

**The test:** `AnthropicSdkAbsentTest` loads this module, core and Gson in a class loader without the SDK, as the release
jar has them. There:
- the SDK's `AnthropicClient` is not found;
- asking for the Anthropic provider throws a `LinkageError` naming `com/anthropic`;
- the OpenAI provider is still built, an `OpenAiCompatibleStrategist`.
