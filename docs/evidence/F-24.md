# F-24 — Bounded block perception (chunk-section scan with palette prefilter, exposure filter and per-tick budget)

Date: 2026-10-13
Agent / branch: Cursor / Antigravity agent, uncommitted working tree
Build: uncommitted; tested artifact `companion-server-adapter/build/libs/kindred-mc-0.1.0-SNAPSHOT.jar`
Status: complete

## Scope and implementation

User-visible behavior:
- `/companion look [block] [UUID]`: asks what the companion sees right now. Perception scans the companion's allocated work area clipped to a bounded 9-chunk horizontal area and 5-section (80 block) vertical band around the body, ordered nearest section first.
- The command acknowledges immediately and responds upon completion of the perception pass with structured diagnostic facts: pass number, sections planned, ticks taken, breakdown of sections scanned, skipped by palette, empty, or unloaded, max single-tick duration, per-block match and exposed counts, and nearest exposed position and distance.
- Perception runs only while the body holds an active lease or during an explicit owner `look` request; facts are cleared when the chunk unloads, upon world change, or when interest changes.

Changed modules/files:
- `companion-core`:
  - `SectionKey`: 16x16x16 chunk section coordinate abstraction with block coordinate conversion and squared section distance.
  - `BlockObservation`: timestamped, immutable observation of an exposed block with age and distance calculations.
  - `BlockObservations`: immutable per-companion section index with SectionFacts (match counts and exposed lists), summary stats, nearest matching block retrieval with optional patch containment predicate, age limits, and versioning.
  - `SectionPlanner`: clips allocated work region to a bounded range (default 1 chunk horizontally, 2 sections vertically = up to 45 sections), clamped to world height, sorted nearest first.
  - `BlockPerception`: incremental budgeted section scanner with configurable per-tick limits (`sectionsPerTick=16`, `detailedSectionsPerTick=2`, `matchesPerSection=256`, `exposedPerSection=32`), palette prefiltering via `mayContain`, skipping of empty/unloaded sections, pass accounting, and snapshot generation.
- `companion-server-adapter`:
  - `ChunkSectionSource`: server-thread `SectionSource` accessing `world.getChunkManager().getWorldChunk(x, z)` (returns null if unloaded, never requests chunk load), palette prefiltering via `section.hasAny(...)`, and 6-direction exposure evaluation treating unloaded neighbours as hidden.
  - `CompanionCommands`: registers `companion look [block] [UUID]`.
  - `CompanionRuntime`: integrates `tickPerception` into runtime tick loop for active leases or pending look requests; retargets on movement across sections, setup revision, or interest change; provides `look` command handling with ownership validation and async pass completion reporting.
- Tests:
  - `BlockPerceptionTest`: 6 unit tests in `companion-core`.
  - `PerceptionGameTests`: 5 native Fabric GameTests in `companion-server-adapter`.
