## The question (the lead, 2026-11-23)

Rung c's bar counts a safe return. With rods in hand and too few pearls, the planner never reaches RETURN, so the
player stays in the Nether. When should it go home without the 12 pearls?

## What the planner does today (`StrongholdRunPlanner`, `StrongholdLeg`)

**In the Nether** (`stage`):
- while the rods are short, FORTRESS or BLAZE_RODS;
- then PEARLS until `netherDone`, then RETURN ("Back through the portal with rods and pearls").

`netherDone` needs one of:
- 12 pearls or eyes (`PEARLS_TARGET`);
- or the pearl hunt stalled **and** `eyesPossible() >= EYES_MIN` (6).

`eyesPossible` is eyes plus the smaller of pearls and powder plus two per rod. So with no pearls it is 0, and a
stalled hunt never ends the stage.

The stall itself (`StrongholdLeg`, `PEARL_STALL_TICKS`) is 10 game minutes of PEARLS without a new pearl.

**In the Overworld**, a player that is back with rods but no pearls has `eyesPossible` 0, below 6. So its stage is
NETHER again (or PREPARE). There is no Overworld pearl stage: RETURN alone would send it back and forth.

**Where pearls come from:**
- `seekEnderman` goes to a warped forest it knows of, and otherwise explores as the fortress search does.
- An enderman in sight is fought (`FIGHT_ENDERMAN`) whatever the stage.
- Nothing barters with piglins: no code path in `StrongholdLeg`, `PortalRunCampaign` or the planner.

## Proposal

Earned only: no free pearls, and no enderman or structure found from the world's data. The pearls come from endermen
it meets, as now.

1. **In the Nether, go home once the rods are done and the pearl hunt has stalled**, whatever the pearl count.
   `stage` would return RETURN when `!rodsShort(s) && s.pearlHuntStalled()`. The rule with enough pearls stays as it
   is. The stall stays as it is, 10 game minutes of PEARLS without a new pearl; Sol would have started home around
   minute 65, with some 120 game minutes left.
2. **In the Overworld, with the rods and too few pearls, hunt endermen there,** not back to the Nether. `stage` would
   return PEARLS when `!rodsShort(s) && s.eyesPossible() < needed`. The existing `seekEnderman` and the
   enderman-in-sight fight would hunt as they do in the Nether.
   - Endermen spawn in the dark on the Overworld's surface and wander by day. This meets the night rules, which
     shelter it: the plan would hunt at dusk and dawn, and by day in the open, within the night rules as they are,
     not overriding them.
   - Back to the Nether for pearls only if it has seen a warped forest (its own sightings) and the Overworld hunt has
     stalled for a whole night. That is an option to decide, not in the first slice.
3. **RETURN as it is:** the walk back through the portal it came by (`StrongholdLeg.enterPortal`). Rung c's "a safe
   return" is then counted as the walk back through with the rods and alive.
4. **Not in this slice:** piglin barter. It is earned (the player's own gold) and the gold is there, but a pearl is
   about 2% of a barter, so it is many ingots a pearl. That is its own lever if e40c5 shows the Overworld hunt short.
