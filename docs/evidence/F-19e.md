## Scope and implementation

User-visible behavior. The optional strategist now has a general Minecraft guide, and can think ahead for the player:
- the guide is bundled with the model module and sent with the instructions on every request, unchanged, so a provider that caches prompts reads it back at a tenth of the price. It covers:
  - the way to the Ender Dragon;
  - what each larger task needs before it begins;
  - recipes, and where things come from;
  - how far mobs notice a player, and the dangers;
  - how the player's queue works;
- the report shows the player's queue: what each task ahead wants, what it holds, and the work left (F-25c7);
- a reply may add up to three follow-ups: a need from the fixed list, a count and the task it is for, with a reason. Core validates them, as it validates the rest of a reply. The player gathers and crafts them itself, when the chance comes and before the task, and drops them when met or when their task is behind it;
- the follow-ups are kept in the player's memory of the world, beside its notes and habits, across restarts;
- daily token budgets now count input read back from the cache at a tenth, as it is billed. Without that, the guide's longer instructions would have used up the steady default (50,000 a player) after about ten consultations a day.

Changed modules/files:
- `minecraft-guide.md` (new, `companion-model` resources).
- `StrategistPrompt`: the guide after the instructions, which now cover the whole way to the End and thinking ahead, and the queue's fields.
- `ClaudeStrategist`, `OpenAiCompatibleStrategist`: the `queue` field in the structured reply, the strict JSON schema and JSON mode.
- `StrategyAdvice` (core): `queue`, validated (one want a need, three at most).
- `ModelContextStore`: the follow-ups kept in the context file. `StrategistBridge`: handed to each goal like habits, written back as the goal settles them, logged, and the budgets as above.
- `PortalRunCampaign`: the strategist's wants join the queue.
- Tests: `OpenAiCompatibleStrategistTest`, `StrategyAdviceTest`, `ClaudeStrategistLiveTest` (opt-in), `memoryKeepsHabitsWithTheirNotesAcrossASave`.

Dependencies satisfied: F-19b, F-19c, F-19d; F-25c7 (the queue).
Schema/configuration changes: the context file gains `queue`; files without it read as an empty queue.
