## Scope and implementation
User-visible behavior: Physical defensive combat execution, entity retreat from creeper fuse/swarms, and emergency night shelter/barricade placement for autonomous AI players.
Changed modules/files:
- `companion-server-adapter`:
  - `NativePlayerBody.java`: Added `Intent.ATTACK` and `Intent.BLOCK`. Implemented `attack(ActionLease lease, UUID targetId, int slot)` verifying target reach (<= 4.0 blocks), sightline raycast, authentic yaw/pitch orientation, weapon slot selection, hand swinging, and target attack dispatch. Implemented `block(ActionLease lease, boolean active)` handling shield usage in main hand or off-hand, raising shield item, and synchronously clearing active item on completion.
  - `NativePlayerSkills.java`: Registered `native_attack` and `native_block` descriptors. Implemented `Attack` skill verifying attack cooldown charge >= 0.9f and target damage, and `Block` skill holding shield raised for specified duration.
  - `NativeAttackAction.java`: Implemented durable action admission wrapper for `Attack` with strict item conservation: weapon durability damage <= 2, and bit-for-bit conservation of all other 35 inventory slots, armor slots, and off-hand slot.
  - `PlayerRuntime.java`: Integrated autonomous combat dispatch (`tactical_attack`, `tactical_block`, `tactical_retreat`, `creeper_retreat`, and `night_barricade`). Guarded tactical combat candidate generation with observed mob presence to preserve normal autonomous chore execution. Creeper retreat candidate prioritized at URGENT 98.0 with single-step verified escape direction. Autonomous night barricade placement prioritized at URGENT 95.0 within designated work area and verified block clearance.
  - `PlayerCommands.java`: Registered `/aiplayer native attack <player> <target-uuid> [slot]` and `/aiplayer native block <player> [ticks]`.
  - `NativeCombatGameTests.java`: Authored 4 comprehensive acceptance GameTests. Registered test class in `fabric.mod.json`.
