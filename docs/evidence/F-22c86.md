## Scope and implementation

**User-visible behaviour:** an animal of the herd a pen run began with that slips out of the gate as the player goes in is
fetched back before the run is called done. Before, the run could end "done" with that animal outside.

**Found:** `NativeOwnRanchGameTests.itsCowPenRunOnceItBreedsThePairAgainAfterTheWait` failed in CI with two cows in the
pen and one out ("2 and 1").

**Cause (core), in `Ranch`:**
1. The planner fetches back only animals in its `penned` set when they leave (`escaped()`, up to `RETURNS` times).
2. An animal joined `penned` only when it was brought in during FETCH.
3. In a second run, the herd was already inside when the run began, so none of it was in `penned`. If one slipped out as
   the player opened the gate and stepped in, nothing fetched it back, and the run finished with it outside.

**The change:** at the BUILD → FETCH turn, every animal of the run's kind already inside the pen joins `penned`. The
existing return then fetches it back if it leaves. No new retry, no new count. An animal of another kind inside is not
counted.

**Nothing granted.** Changed files:
- `companion-core`: `Ranch` (the BUILD → FETCH turn).
- Tests: `RanchTest` (two cases), `NativeOwnRanchGameTests` (`aCalfThatSlipsOutAsItGoesInIsBroughtBackBeforeItIsDone`,
  batch `ownRanchHerdCalfOut`, new; the cow-pen test's failure message now lists every cow, where, and in or OUT).
