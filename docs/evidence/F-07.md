# F-07 — Physical inventory, equipment and verified item transfer primitives

Date: 2026-10-13
Agent / branch: Antigravity agent, uncommitted working tree
Build: uncommitted; tested artifact `companion-server-adapter/build/libs/kindred-mc-0.1.0-SNAPSHOT.jar`
Status: complete

## Scope and implementation

User-visible behavior:
- Companions carry items in 27 native inventory slots saved directly with the entity in the Minecraft world save. Metadata never stores synthetic items.
- Tools and weapons equipped in hand (`main_hand`) reflect actual items in the companion's inventory; an item not owned cannot be equipped.
- Transfers between companion inventory and assigned containers conserve exact items: source count reduction matches container count increase, and any partial capacity immediately rolls back remaining items into the companion inventory.
- Item pickups attribute only the specific requested item, leaving unrelated items on the ground.

Changed modules/files:
- `companion-core`:
  - `InventorySummary`: immutable record capturing monotonic inventory revision, total item count, occupied slots, total capacity, and per-item count map.
  - `InventorySummaryTest`: 3 unit tests verifying defaults, count queries, occupancy, and immutability.
- `companion-server-adapter`:
  - `CompanionEntity`: 27 native slots with `SimpleInventory`, change listener bumping monotonic `inventoryRevision`, `summary()` snapshot generator, `equipFromInventory` and `clearEquipment` helpers, and NBT serialization of inventory and revision.
  - `ItemMoves`: `TransferResult` and `PickupResult` records with before/after evidence strings and reconciliation assertions; `transfer(...)` with automatic excess rollback for strict item conservation; `attributedPickup(...)` distinguishing wanted item receipts from unrelated ground entities.
  - `ChoreSkills`: Gather and Deposit refactored to use `ItemMoves.attributedPickup` and `ItemMoves.transfer`.
  - `InventoryGameTests`: 6 native Fabric GameTests.
  - `fabric.mod.json`: registered `InventoryGameTests` in gametest suite.
