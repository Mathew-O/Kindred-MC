**The change (`PortalRunCampaign`):**
- `leavesToDrop(body, at, label)` breaks the first block between its eyes and the drop when that block is leaves, labelled "Clear the leaves to the drop: …". The dispatch checks the break again. At most `LEAF_CLEARS` (4) breaks to a cell.
- A refused "Pick up" walk is not set aside at once. Its next look tries `leavesToDrop`, and with nothing to break sets the drop aside as before.
- `intoTheDropsCell` tries `leavesToDrop` before it sets a drop aside.
- Anything else in the way, or a rule refusing the break, leaves the drop set aside as before.
