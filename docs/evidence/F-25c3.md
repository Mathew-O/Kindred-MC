# F-25c3 — Autonomous local survival, 3D approach traversal, and tool crafting progression
Date: 2026-10-17 EDT; report 2026-10-17.
Codex / uncommitted main, no commits. Complete for this child; parent F-25 remains open.

Autonomous local survival progression links real physical player mechanics (eating, crafting, table placement, 3D traversal approach, and tool-assisted harvesting) into `PlayerRuntime.evaluateNativeCandidates`. When an authorized native player operates with enabled edit policy, the runtime decision loop evaluates autonomous task candidates with rigorous survival priority:
1. Urgent consumption (`native_eat`) when hunger allows eating.
2. In-reach scoped block harvesting (`native_mine`) targeting assigned resource patches within reach.
3. 3D terrain approach traversal (`native_traverse`) when scoped resource blocks are located within search radius (12 blocks) but out of immediate interaction reach, utilizing bounded 3D traversal steps.
4. Autonomous crafting and workstation deployment progression:
   - Workstation crafting of wooden pickaxe (`wooden_pickaxe`) at 3x3 table using owned planks and sticks.
   - Basic 2x2 field crafting of sticks (`stick`) when planks are owned.
   - Workstation deployment (`native_place`) targeting valid adjacent positions in the work scope, transferring crafting table from main inventory into hotbar when required.
   - Workstation crafting (`crafting_table`) in 2x2 grid from 4 planks.
   - Material breakdown (`oak_planks`) from gathered logs.

Every autonomous action executes strictly through the shared `ActionArbiter`, `SkillRunner`, and durable SQLite accounting; zero synthetic items, zero cheats, and zero teleportation shortcuts.
