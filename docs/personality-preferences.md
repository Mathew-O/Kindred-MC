# AI-player personality
Nine independent 0–100 traits: initiative, caution, curiosity, sociability, humor, combativeness, helpfulness, farming and mining. Neutral activity interests are 50; command aliases are not professions.

Reuse TaskPreferences: eligibility/urgency precede a combined bias bounded to five points, with checkpoint switching hysteresis. Preferences never create skills, permissions, time or items. Low initiative affects discretionary work, not survival or accepted commitments.

New UI describes an autonomous player, its needs/goals and team commitments. Legacy mode records are not a new autonomy selector. F-17 owns local selection; E-10 optional UI. Console ranking demonstrations are not native gameplay.
